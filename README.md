# commune_gouv_fr

Projet de diffusion de publications pour les 34 875 communes de France.

## Objectif

Faciliter la diffusion de publications à destination des communes françaises.

## Périmètre cible

Le projet vise les 34 875 communes de France, selon le périmètre défini à son lancement.

## État du projet

Le dépôt est initialisé. Les types de publications, les publics utilisateurs et les canaux de diffusion restent à définir.
