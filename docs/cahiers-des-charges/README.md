Les identifiants de démonstration éventuellement présents sont volontairement publics et fictifs. Ils ne constituent ni une preuve d'identité ni une habilitation officielle. Les exigences de la version définitive sont distinguées des fonctions du prototype.

La version confidentielle est exclue de ce répertoire et du dépôt. Aucun accès administrateur privé, secret de base de données ou clé d'accès au serveur ne doit être ajouté à cette documentation.
